## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Prospective Evaluator Input → DOM & Admin Leads (`#tk-proposal-form`) | Untrusted contact name, company, market, and notes rendered into modal confirmation and Admin Buyer & Partner Leads table |
| Browser → Downloaded CSV File (`exportCsvFile`) | User-supplied lead fields exported to CSV opened in spreadsheet applications |
| External Link Boundary (`wa.me` WhatsApp CTA) | User-supplied inquiry fields serialized into WhatsApp query parameters |
| LocalStorage Persistence (`glamgo-turnkey-leads-v1`) | Client-mutable JSON loaded on startup |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-12 | Tampering (XSS) | `src/turnkey-showcase.js` (`renderProposalModalContent`, `renderAdminTurnkeyLeadsPanel`) | high | mitigate | Escape every user-supplied lead field (`name`, `email`, `phone`, `company`, `market`, `notes`, `previewBrand`) through `esc()` before HTML interpolation. |
| T-13-13 | Tampering (CSV Formula Injection) | `src/dashboards-suite.js` (`sanitizeCsvCell`, `exportCsvFile`) | medium | mitigate | Prefix any CSV cell beginning with `=`, `+`, `-`, `@`, tab, or CR with a single quote (`'`) before RFC-4180 quoting so spreadsheet apps treat exported lead cells strictly as text. |
| T-13-14 | Information Disclosure / Corrupt Storage | `src/turnkey-showcase.js` (`loadTurnkeyLeads`, WhatsApp CTA) | low | mitigate | Wrap `localStorage` parsing in `try/catch` with fallback to `DEFAULT_TURNKEY_LEADS`; hardcode trusted `https://wa.me/` origin with `encodeURIComponent` and `rel="noopener noreferrer"`. |
| T-13-SC-04 | Tampering | npm/pip installs (Plan 13-04) | high | mitigate | Zero new npm or pip packages added in Plan `13-04`; existing locked dependencies only. |
</threat_model>
